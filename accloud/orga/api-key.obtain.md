
Do I need an API key?
---------------------

If you use the regular browser-based Chat AI, no, your browser will deal
with that. However, if you're trying to help with this project here,
it may be useful to submit directly from your CLI, because you can then
post-process the answers more easily:

* Compare outputs for the same question using different system prompts or
  file upload encoding formats.
* Use the system message to request a custom encoding for file replies
  that would otherwise run into markdown syntax limitations.
* Automatically split the reply into local files. (Be careful about paths!)

Since those are legit AI research topics, your scientific effort will likely
qualify for requesting a [SAIA key][gwdg-docs-saia].
The [request form][kisski-request-saia] asks for a website for your research
project, and you will have to provide a report about what you have discovered.
Your public clone of this repo might work as that website, and if you regularly
commit your lab notes to some branch, you can later ask Chat AI to summarize
them for your report.

  [gwdg-docs-saia]: https://docs.hpc.gwdg.de/services/ai-services/saia/index.html
  [kisski-request-saia]: https://services.kisski.de/services/en/service/?service=2-02-llm-service.json


### ⚠ Requesting an API key is a slow process, with a few anomalies.

* The resulting email was a notification that a support ticket was opened,
  with no details about the request. So if you want to keep a copy of the
  form data you submitted, it seems you have to print the page to PDF
  before you submit the form.
* About 18 hours later (18hr&minus;30sec), an automated response claimed it
  couldn't find a user account for my email address, although I was logged
  in with that exact email address when I submitted the form.
  Strange. If the check is automated, why does it take &asymp;18 hours?
  Anyways, I followed the instructions to contact support,
  so I hope my request will make it to the human review stage soon.
